# LoanMatch

Website demo cho dự án LoanMatch – cung cấp thông tin và so sánh các sản phẩm vay dành cho khách hàng cá nhân theo mục đích vay.

## Chức năng prototype

- Trang chủ
- Chọn mục đích vay
- Lọc sản phẩm theo danh mục
- Trang chi tiết sản phẩm
- Bảng so sánh giữa MB, Vietcombank, VietinBank và BIDV
- Tính khoản vay
- Trang giới thiệu
- Trang liên hệ

## Chạy project

Mở thư mục `loanmatch` bằng VS Code và dùng Live Server để chạy `index.html`.

Không nên mở trực tiếp `products.html` bằng `file://` vì trang này sử dụng `fetch()` để đọc file JSON.

## Lưu ý dữ liệu

Thông tin ngân hàng trong bản prototype chỉ là dữ liệu mẫu để lập trình giao diện. Trước khi nộp dự án, nhóm cần thay bằng dữ liệu đã kiểm chứng từ nguồn chính thức.
